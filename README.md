# 🌳 English Sentence Analyzer (PWA Complete)

Bộ ứng dụng phân tích cú pháp, thành phần câu (S-V-O-C-A), vẽ sơ đồ cây ngữ pháp (Tree Diagram), phát hiện lỗi sai và gợi ý hoàn thiện câu theo ngữ cảnh dành cho học sinh & giáo viên.

## 📦 Cấu trúc Thư mục Dự án

```
English_Sentence_Analyzer/
├── index.html        # Giao diện chính 100% & Mã nguồn bộ phân tích đầy đủ
├── manifest.json     # Cấu hình PWA (Thêm vào màn hình chính)
├── sw.js             # Service Worker chạy Offline 100%
└── README.md         # Hướng dẫn sử dụng & Cài đặt
```

## 🚀 Hướng Dẫn Nhanh

1. Mở file `index.html` trực tiếp trên trình duyệt (Chrome, Safari, Edge, Cốc Cốc) để sử dụng ngay.
2. Hoặc upload toàn bộ 4 file này lên **GitHub Pages** / **Vercel** để tạo đường link web truy cập từ xa.
3. Cài đặt thành App trên iPhone/Android bằng cách chọn **Add to Home Screen** / **Cài đặt ứng dụng**.
